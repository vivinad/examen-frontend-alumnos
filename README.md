# Frontend Angular - Gestión de alumnos

Lista y elimina alumnos consumiendo la API REST de Spring Boot.

## Ejecutar en Codespaces

1. Editar `apiUrl` en `src/app/services/alumno.ts` con la URL pública del puerto 8080 del backend.
2. Ejecutar:

```bash
npm install
npm start
```

3. Abrir el puerto 4200 desde la pestaña Ports.
